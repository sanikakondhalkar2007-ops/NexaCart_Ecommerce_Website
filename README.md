# NexaCart — Smart E-Commerce Website

A ready-made college project built with Python, Flask, SQLite, HTML, CSS and JavaScript.

## Features
- Modern responsive home page
- Product catalogue and search
- Categories and product details
- Shopping cart
- Checkout and demo order storage
- Product comparison
- Nexa AI-style product recommendation
- Admin dashboard
- SQLite database with sample products

## How to run in VS Code

1. Install Python if it is not already installed.
2. Open this NexaCart folder in VS Code.
3. Open **Terminal → New Terminal**.
4. Run:

```bash
python -m pip install -r requirements.txt
```

5. Start the website:

```bash
python app.py
```

6. Open the address shown in the terminal, normally:

http://127.0.0.1:5000
